# Python Data Structure List, Set, Dictionary & Conditional Statement

This repository focuses on working with core Python data structures and controlling program flow using conditional statements.

## 📌 Objectives
* Master **List** creation, modification, and indexing operations.
* Understand **Dictionary** manipulation using unique key-value pairs.
* Explore **Set** operations, focusing on uniqueness, union, and intersection propertie.
* Implement decision-making workflows using conditional structures (`if-elif-else`).

---

## 💻 Assignment Breakdown & Key Tasks

### 1. Python Lists

* **Creation:** Initialized lists for processing integers (`Age_list`) and strings (`Name_list`).
* **Modifications:** Demonstrated list mutation techniques using `.append()`, `.insert()`, `.remove()`, `.pop()`, and `.extend()`.
* **Data Processing:** Utilized Python built-ins (`max()`, `min()`, `sum()`) along with list `.sort()` and `.reverse()` methods to analyze numeric sequence.
* **Slicing & Access:** Managed absolute and relative boundary selection via regular indexing, negative indexing, and range slicing.

### 2. Dictionaries

* **Mapping:** Structured a `Student_marks` dataset grouping unique student entities with numeric scores.
* **CRUD Operations:** Practiced reading specific keys, writing new student records, and overwriting existing score values.
* **Extraction Methods:** Evaluated structural details through explicit usage of `.keys()`, `.values()`, and `.items()` methods.

### 3. Sets

* **Deduplication:** Evaluated set behavior showing automatic truncation of repeating items upon initialization.
* **Index Error Resolution:** Addressed index limitations (`Type Error` troubleshooting) explaining why sets lack traditional item positional indices.
* **Venn Set Math:** Performed Boolean set evaluation using `.union()` and `.intersection()` functions across separate sets.
